✦ Kết nối OpenRouter API

Nova AI sử dụng OpenRouter để truy cập hàng chục model AI (Perplexity, Claude, GPT-4o, Llama...) qua một API key duy nhất.

1
Đăng ký tại openrouter.ai → Vào Keys → Tạo API Key mới.
2
Nạp credit vào tài khoản (tối thiểu $5) hoặc dùng các model miễn phí (DeepSeek, Llama).
3
Dán key bên dưới. Key lưu trong trình duyệt của bạn, không gửi đi đâu ngoài OpenRouter.
