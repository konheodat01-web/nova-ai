✦ Chào mừng đến Nova AI

Để sử dụng trợ lý, bạn cần có Gemini API Key miễn phí từ Google AI Studio.

1
Truy cập aistudio.google.com/app/apikey và đăng nhập bằng tài khoản Google.
2
Nhấn "Create API key" → chọn project (hoặc tạo mới) → Copy API key.
3
Dán key vào ô bên dưới. Key được lưu trong trình duyệt của bạn, không gửi đi đâu ngoài Google.
